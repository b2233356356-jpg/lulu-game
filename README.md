# 水豚噜噜大冒险

这是可直接部署到 GitHub Pages 的静态 HTML5 游戏。

## 发布
1. 登录 GitHub，创建 Public repository，例如 `lulu-game`。
2. 上传本压缩包中的 `index.html` 到仓库根目录。
3. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save。
4. 等待 GitHub Pages 发布。地址通常是 `https://用户名.github.io/lulu-game/`。

## 修改
以后替换仓库中的 `index.html` 即可在同一个网址更新。
